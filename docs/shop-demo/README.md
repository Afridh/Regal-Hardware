# Shop redesign demo

A look-and-feel demo of a new regalhw.lk online shop. Open `index.html` in a browser from this folder; it uses the photos and logos already in `frontend/`.

- Prices and sizes are samples made up for the demo. Orders are not sent anywhere.
- It lives under `docs/`, which is never deployed, so it cannot appear on the live site.
- The real shop is `frontend/shop.html`; this design is meant to be carried over to it.
